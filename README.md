# Sakasa (逆さ, "upside down")

Your room is the level; you choose which way is down. Pinch a real surface (floor, wall, table,
ceiling) and it becomes "down": everything virtual falls onto it.

Entry for the Meta VR Start Developer Competition 2026 (New Experience division, Gaming track).
Built with the Immersive Web SDK (WebXR), hands-only.
